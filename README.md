# Real-Time Observability and Log Analytics Platform

A production-inspired observability platform built using React.js, Node.js, Express.js, PostgreSQL, and Docker.

## Features

- Real-time monitoring dashboard
- Centralized log analytics
- GIN-indexed full-text search
- Dynamic charts and analytics
- Service-level monitoring
- CSV / JSON export
- Dockerized deployment
- Real-time log simulation

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Recharts

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL
- GIN Indexing
- Full-Text Search

### DevOps
- Docker
- Docker Compose
